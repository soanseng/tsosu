Tsosu 做事

為 ADHD 設計的任務管理器 你的任務就是你的 Markdown 檔案

由精神科醫師設計——把事情變小、變簡單、慶祝進度。本地優先、無帳號、無追蹤，直接同步你的 Obsidian vault。

立即安裝 GitHub 原始碼

Android 原生（Kotlin + Compose）・免費・無廣告・無分析追蹤

為什麼是 Tsosu？

多數任務管理器是為神經典型大腦設計的——逾期數字、無盡選項、落後時的罪惡感。Tsosu 不一樣。

🎯

Focus 3——「只要挑三件。」

每天只挑 3 件今日任務，其餘收進可摺疊的「無日期」區。完成 3 件就放煙火慶祝——其他都是加分。

🔁

每日習慣——「把事情變小。」

兩分鐘習慣、彈性連續紀錄（中斷暫停不歸零 🔥）、7 天進度條、早晚例行分組。靈感來自《原子習慣》。

😌

無羞愧 UI

每個像素都檢視過羞愧與焦慮觸發點。週回顧只看你完成了什麼，絕口不提沒做的。

🎲

「幫我挑一件」

選擇癱瘓是真的。選擇你現在的精力等級，骰子隨機挑一件符合的任務——「就做這件 ✓」。

⏰

任務提醒

每個任務可設提醒時間，到期當天準時通知。點通知直接開任務、直接完成。重開機與同步後自動重排。

📅

日曆自動同步

任務設日期 → 自動建日曆事件；改日期 → 事件跟著搬；完成 → 事件移除。支援 CalDAV（Fastmail、Nextcloud）與 Google 日曆。

📝

Markdown Vault

一切皆純文字 Markdown，存在你自己的資料夾。在 Obsidian、nvim 或任何編輯器雙向編輯，Tsosu 下次同步自動接上。

📥

Todoist 匯入

從設定匯入 Todoist CSV 匯出檔——任務自動去重、寫成 Markdown、推進你的 vault。

安裝

推薦使用 Obtainium——直接追蹤 GitHub Releases，新版自動通知更新。

透過 Obtainium 安裝（推薦）

  1. 在 Google Play 或 F-Droid 安裝 Obtainium。
  2. 打開 Obtainium，點右下角 ＋ 新增應用程式。
  3. App 來源選 GitHub，輸入 soanseng/tsosu
  4. 點新增——Obtainium 會自動下載最新版 APK；之後有新 Release 也會自動提醒更新。

不想用 Obtainium？直接到 Releases 頁面下載最新 .apk 安裝即可。Android 會詢問「安裝未知應用程式」權限，允許後即可安裝。

跨裝置同步

本地優先——100% 離線可用、無帳號。資料是純 Markdown 檔案，用任何檔案同步工具帶到每台裝置。

裝置使用方式
📱 手機Tsosu App（完整 UI、習慣追蹤、Focus 3、提醒）
💻 電腦Obsidian + Tasks 外掛——核取方塊、到期日、篩選器
⌨️ 終端機nvim / 任何文字編輯器——就只是 Markdown

資料夾用 Syncthing 或 Obsidian Sync 同步，任務就出現在每台裝置上。檔案格式完整文件見 README。

隱私至上

無帳號、無伺服器、無分析、無追蹤、不收集任何資料。你的任務只存在你自己的裝置與 vault 裡。
